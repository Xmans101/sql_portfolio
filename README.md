# Telegram Бот для сбора имени и возраста

Этот бот запрашивает у пользователей их имя и возраст, а затем показывает собранную информацию.

## Возможности

- 🚀 Простой и понятный интерфейс
- 📝 Сбор имени и возраста пользователя
- ✅ Валидация введенных данных
- 🔄 Возможность начать разговор заново
- 📱 Поддержка команд /start, /help, /cancel

## Установка и настройка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Получение токена бота

1. Найдите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен

### 3. Настройка конфигурации

Откройте файл `config.py` и замените `YOUR_BOT_TOKEN` на ваш токен:

```python
BOT_TOKEN = '1234567890:ABCdefGHIjklMNOpqrsTUVwxyz'
```

### 4. Запуск бота

```bash
python telegram_bot.py
```

## Использование

### Команды бота

- `/start` - Начать разговор и ввести данные
- `/help` - Показать справку
- `/cancel` - Отменить текущий разговор

### Процесс работы

1. Пользователь отправляет `/start`
2. Бот запрашивает имя
3. Пользователь вводит имя
4. Бот запрашивает возраст
5. Пользователь вводит возраст
6. Бот показывает собранную информацию

## Технические детали

- **Python**: 3.7+
- **Библиотека**: python-telegram-bot 20.7
- **Архитектура**: Асинхронная с использованием ConversationHandler
- **Состояния**: NAME, AGE для управления диалогом

## Безопасность

- Токен бота хранится в отдельном конфигурационном файле
- Валидация введенных данных (возраст от 0 до 150 лет)
- Очистка данных пользователя после завершения разговора
